Bot musik Discord yang jalan di satu proses Node.

music-dc muter lagu dari YouTube dan ratusan situs lain pakai yt-dlp dan FFmpeg. Nggak pakai Lavalink, Java, atau Docker. Cocok buat server tongkrongan yang di-host sendiri.

02

Cara kerja

Jalan yang dilewati satu lagu dari /play sampai voice channel. Klik tiap tahap buat lihat detailnya.

Kenapa audionya lewat 127.0.0.1?

Versi awal nyuruh FFmpeg buka URL audio YouTube langsung. Sesekali lagu gagal dengan exit code yang nggak masuk akal. Ternyata itu kode error FFmpeg untuk HTTP 403. Sekarang yt-dlp yang download audionya, dan FFmpeg cuma baca dari server lokal.

  1. $ffmpeg exited with code 3436169992
  2. 1int32 → −858797304
  3. 2hex → −0x333034F8
  4. 3FFERRTAG(0xF8, '4', '0', '3')
  5. =AVERROR_HTTP_FORBIDDEN (403)
03

Fitur

Judul, link, dan playlist

YouTube, SoundCloud, Bandcamp, dan situs lain yang didukung yt-dlp.

Playlist besar tetap cepat

Dibaca pakai --flat-playlist. Playlist 182 lagu masuk antrian dalam ±4 detik.

Voice terenkripsi (DAVE)

@discordjs/voice 0.19 sudah support E2EE yang wajib di Discord sejak Maret 2026.

yt-dlp update sendiri

Didownload ke bin/ dan di-update tiap bot start.

Cookies opsional

Buat video yang minta login. Disarankan pakai akun Google cadangan.

Auto-leave

Keluar 2 menit setelah antrian habis, atau 1 menit setelah voice channel kosong.

Banyak server sekaligus

Antrian, volume, dan mode loop terpisah per server.

Gagal nggak bikin crash

Lagu yang gagal dilaporin dengan pesan aslinya, lalu bot lanjut ke lagu berikutnya.

04

Instalasi (Windows)

yt-dlp nggak perlu di-install, karena bot download sendiri waktu pertama start. Cookies dan troubleshooting ada di README.

Install Node.js dan FFmpeg

Habis itu tutup lalu buka lagi terminal-nya supaya PATH ke-refresh.

winget install OpenJS.NodeJS.LTS
winget install Gyan.FFmpeg

Clone dan isi .env

Isi DISCORD_TOKEN dan CLIENT_ID dari Discord Developer Portal.

git clone https://github.com/adrawsf/music-dc.git
cd music-dc
copy .env.example .env

Install, daftarkan command, jalankan

Lalu masuk voice channel dan ketik /play.

npm install
npm run deploy
npm start
PowerShell

Streaming dari YouTube melanggar ToS YouTube. Pakai buat server pribadi atau tongkrongan, jangan dipublikasikan atau dimonetisasi. Nggak berafiliasi dengan Discord maupun YouTube.
