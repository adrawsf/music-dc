    Bonus track · cerita bug

    Kenapa audionya lewat 127.0.0.1?

    Versi awal nyuruh FFmpeg buka URL audio YouTube langsung, dan sesekali gagal dengan exit code yang aneh. Setelah dibongkar, angka itu ternyata kode error FFmpeg buat HTTP 403. Sekarang yt-dlp yang download, dan FFmpeg cuma baca dari server lokal.

    1. $ffmpeg exited with code 3436169992
    2. 1int32 → −858797304
    3. 2hex → −0x333034F8
    4. 3FFERRTAG(0xF8, '4', '0', '3')
    5. =AVERROR_HTTP_FORBIDDEN (403)
    403 nggak lagi!

    Release

    instalasi di windows

    1. Install Node.js & FFmpeg

      Habis itu tutup lalu buka lagi terminal-nya supaya PATH ke-refresh.

      winget install OpenJS.NodeJS.LTS
winget install Gyan.FFmpeg

    2. Clone & isi .env

      Isi DISCORD_TOKEN dan CLIENT_ID dari Discord Developer Portal.

      git clone https://github.com/adrawsf/music-dc.git
cd music-dc
copy .env.example .env

    3. Install, daftarkan, jalankan

      Lalu masuk voice channel dan ketik /play.

      npm install
npm run deploy
npm start
