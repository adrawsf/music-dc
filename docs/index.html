Cerita bug

Kenapa audionya di-pipe lewat 127.0.0.1?

Awalnya FFmpeg buka URL audio YouTube langsung, dan sesekali gagal dengan kode error yang aneh banget. Setelah dibongkar, ternyata itu cuma HTTP 403 yang dibungkus jadi angka. Sekarang yt-dlp yang download sendiri, dan FFmpeg cuma baca dari pipa lokal, jadi masalah ini hilang.

✗ffmpeg exited with code 3436169992
→sebagai int32: −858797304
→hex: −0x333034F8
→FFERRTAG(0xF8, '4', '0', '3')
✓AVERROR_HTTP_FORBIDDEN · HTTP 403

Kecil, tapi nggak setengah-setengah.

Semua yang lo harapin dari bot musik buat server tongkrongan, tanpa ribet ngurusin infrastruktur.

🔐
DAVE

Voice terenkripsi end-to-end

@discordjs/voice 0.19 sudah support protokol E2EE yang wajib di voice Discord sejak Maret 2026.

🎵

Putar dari mana aja

Judul, link video, playlist YouTube, SoundCloud, Bandcamp, dan ratusan situs lain yang didukung yt-dlp.

🔄

yt-dlp auto-update

Didownload otomatis dan di-update tiap bot start. Kalau YouTube berubah, cukup restart.

🍪

Cookies opsional

Buat video yang minta login atau "confirm you're not a bot". Pakai akun cadangan.

👋

Tahu kapan harus cabut

Keluar 2 menit setelah queue habis, atau 1 menit setelah voice channel kosong.

🏠

Multi-server

Queue, volume, loop, dan timer terpisah per server. Server A dan B bisa muter bareng.

🛟

Gagal? Lanjut aja

Lagu yang gagal diputar dilaporin dengan pesan aslinya, lalu bot lanjut ke lagu berikutnya tanpa crash.

04 · Mulai

Jalan di PC Windows lo dalam beberapa menit.

yt-dlp nggak perlu di-install manual, karena bot download sendiri pas pertama kali start. Panduan lengkapnya (cookies, troubleshooting) ada di README.

Install Node & FFmpeg

Habis install, tutup lalu buka lagi terminal-nya biar PATH ke-refresh.

winget install OpenJS.NodeJS.LTS
winget install Gyan.FFmpeg

Clone & isi .env

Isi DISCORD_TOKEN dan CLIENT_ID dari Discord Developer Portal.

git clone https://github.com/adrawsf/music-dc.git
cd music-dc
copy .env.example .env

Install, daftarkan command, jalan!

Masuk voice channel, terus ketik /play di Discord.

npm install
npm run deploy
npm start
